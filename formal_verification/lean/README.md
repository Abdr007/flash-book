# Lean 4 proofs — haircut conservation & solvency (real 1e9 divisor)

Machine-checked proofs (Lean 4.24.0 + Mathlib v4.24.0) of two haircut invariants
over the **actual** denominator `H_DENOM = 1_000_000_000`.

## Why this complements the Kani proofs

The Kani proofs in `programs/flash-book/src/matcher/haircut.rs` are bounded model
checking (CBMC). CBMC cannot decide 128-bit division by a non-power-of-two, so
those proofs use a **representative power-of-two divisor** (`D = 1 << 30 ≈ 1e9`)
and document that the result is divisor-agnostic.

Lean has no such limitation. `Haircut.lean` proves the same bounds with the real
`1e9` divisor, over unbounded `Nat`:

| Theorem | Statement | Mirrors Kani proof |
|---|---|---|
| `convert_ensures_0` | `(matured · h) / 1e9 ≤ matured`, given `h ≤ 1e9` | `proof_dust_conservation` |
| `solvency_single_convert` | `(matured · h) / 1e9 ≤ residual`, given `matured·h ≤ backed·1e9`, `backed = min residual matured` | `proof_solvency_single_convert` |

Both are `#print axioms`-clean: they depend only on `propext`, `Classical.choice`,
`Quot.sound` — Lean/Mathlib's three standard axioms. No `sorry`.

## Reproduce

```bash
# one-time: install elan (Lean toolchain manager), see https://leanprover.github.io
cd formal_verification/lean
lake exe cache get      # fetch prebuilt Mathlib .olean cache
lake build              # compiles Haircut.lean; prints the two `#print axioms` lines
```

A successful build ends with `Build completed successfully` and the two
`depends on axioms: [propext, Classical.choice, Quot.sound]` lines.
